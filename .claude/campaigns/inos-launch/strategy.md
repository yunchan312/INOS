# INOS 홍보 전략 — "서가를 자랑하게 하라"

> 2026-07 작성. 초대제 인문학 모임 플랫폼 INOS의 런칭/성장 전략.
> 근거: PRODUCT.md (타깃·브랜드), 구현 완료된 성장 자산(공유 서가 `/s/:shareId`, 연말결산 카드 `/library/recap`, 초대제 구조).

## 1. 포지셔닝

**한 줄**: "모임 준비는 사라지고, 대화와 서가만 남는다."

- 카테고리: 독서/영화 모임 운영 도구 (커뮤니티 매칭 서비스가 아님 — 트레바리·문토와 정면 경쟁하지 않는다)
- 핵심 차별점: **이미 존재하는 모임**의 운영 마찰(일정 조율, 발제문, 아카이브)을 제거하는 유일한 도구
- 앵글: 기능이 아니라 **결과물(서가)** 을 판다. "우리가 함께 읽은 것들이 이렇게 쌓인다"는 심상.
- 톤: 지적이고 아늑하게, 과시 없이. **금지**: "AI가 다 해줘요" 류의 AI 전면 배치(브랜드 원칙), 성장해커식 FOMO 남발, 이모지 범벅.

## 2. 타깃 — 이중 구조

| | 모임장 (구매자) | 멤버 (확산자) |
|---|---|---|
| 누구 | 3~10인 독서·영화 모임을 이미 운영 중인 사람. 트레바리는 비싸고, 카톡+엑셀+웬투밋 조합에 지침 | 모임에 초대받아 들어온 참여자 |
| 페인 | 날짜 조율 지옥, 발제문 준비 부담, 기록이 흩어짐 | 없음(마찰 없이 좋은 경험만) |
| 우리가 파는 것 | "운영 노동의 소멸" | "자랑할 수 있는 내 서가" |
| 행동 목표 | 오가니제이션 생성 신청 | 서가/결산카드 공유 → 신규 모임장 유입 |

핵심: **획득은 모임장 1명, 확산은 멤버 N명이 만든다.** 모든 캠페인은 모임장을 낚고, 제품은 멤버가 퍼뜨리게 설계.

## 3. 성장 루프 (제품 자산 활용)

```
모임장 가입 → 멤버 초대(초대제) → 모임 3회 진행 → 서가가 쌓임
   ↑                                                    ↓
신규 모임장 ← "나도 서재 만들기" CTA ← 서가 링크/결산카드 SNS 공유
```

- **루프 A · 서가 공유**: `/s/:shareId` — 멤버가 자기 서가를 인스타 스토리/스레드에 공유. 페이지의 "나도 서재 만들기 →" CTA가 전환점. *이미 구현됨.*
- **루프 B · 결산 카드**: 연말(12월)·반기(6월)에 "올해의 서재" 카드 캠페인. 스포티파이 Wrapped의 인문학 버전. *이미 구현됨.*
- **루프 C · 초대장**: 초대 이메일 자체가 첫 브랜드 접점. "OO님이 수요 인문학회에 초대했어요" 화면이 스크린샷될 만하게. *디자인 개선 백로그.*
- 희소성 장치: 초대제를 숨기지 말 것. "초대받은 사람들만의 조용한 공간"은 있어빌리티 타깃에게 기능임.

## 4. 채널 전략 (우선순위순)

1. **스레드(Threads)** — 주력. 독서 계정 생태계가 활발하고 텍스트 중심이라 톤이 맞음. 모임 운영 수기 + 서가 스크린샷.
2. **인스타그램** — 비주얼 자산(책꽂이 UI, 결산 카드) 전시. 릴스보다 카드뉴스·스토리 공유 유도.
3. **브런치/개인 블로그** — "독서모임 3년 운영하며 배운 것" 류 SEO성 장문. 모임장 검색 유입("독서모임 일정 조율", "발제문 쓰는 법").
4. **오픈카톡·커뮤니티 침투** — 독서모임 오픈카톡, 당근 동네모임, 디스코드. 광고가 아니라 운영 팁을 나누다 도구로 언급되는 방식.
5. **독립서점 제휴 (오프라인)** — 서점 단골 모임에 초대 코드 제공, 계산대 QR. 브랜드 결이 맞는 저비용 고신뢰 채널.
6. ~~유료 광고~~ — 초대제와 상충. 웨이팅리스트 구축 전까지 보류.

## 5. 4주 런칭 플랜

| 주차 | 테마 | 실행 |
|---|---|---|
| 1주 | 기반 | 스레드/인스타 계정 개설, 프로필·톤 세팅. 브런치 1편("모임 준비가 사라진 날"). 지인 모임 3팀 온보딩(시드) |
| 2주 | 서사 | 시드 모임의 실제 서가 스크린샷으로 스레드 연재 시작(주 3회). "일정 조율 지옥" 밈성 포스트 1개 |
| 3주 | 확산 | 시드 멤버들에게 서가 공유 요청(멤버당 링크 1회). 오픈카톡 2~3곳에 운영 팁 글. 독립서점 1곳 제휴 타진 |
| 4주 | 수확 | "첫 달의 서가들" 모음 포스트. 오가니제이션 생성 신청 오픈 공지. 웨이팅리스트(추후 구현) 연결 |

이후 상시 리듬: 스레드 주 3회, 브런치 월 2편, 분기별 결산 카드 캠페인(6월/12월).

## 6. 핵심 카피 샘플

**헤드라인 후보**
- "함께 읽고, 보고, 생각합니다." (기존 랜딩 유지 — 강함)
- "모임 준비는 사라지고, 대화만 남습니다."
- "우리가 읽은 것들이, 우리의 서가가 됩니다."

**스레드 포스트 3종**
1. (공감) "독서모임 날짜 정하는 데 카톡 47개가 오갔다. 정작 책 얘기는 0개." → 스크린샷 없이 텍스트만, 마지막 줄에 도구 언급 없이 끝 → 댓글에서 언급
2. (전시) 책꽂이 UI 스크린샷 + "3개월치 모임이 이렇게 남았다. 링크 누르면 우리 모임 서가가 보인다." + `/s/...` 링크
3. (철학) "발제문을 잘 쓰는 사람만 모임을 열 수 있는 건 아니라고 생각했다." → 준비 부담 제거 서사

**초대 문구(멤버→친구)**
- "초대받아야 들어올 수 있는 독서모임 앱인데, 한 자리 남았어."

## 7. KPI

- 북극성: **3회차 도달 모임 수** (제품 성공 기준과 동일 — "세 번째 모임까지 앱 없이 운영 안 되는 상태")
- 확산: 서가 공유 링크 생성 수 / 공유 페이지 방문 → "나도 서재 만들기" 클릭률
- 획득: 오가니제이션 생성 신청 수 (주간)
- 채널: 스레드 팔로워보다 **포스트당 저장·공유 수** 우선
